# FinWallet — учебный электронный кошелёк с кредитным калькулятором

Автор: Мануйлик Владислав Николаевич, группа ОБОз-42309МОрпо.

FinWallet — это full-stack веб-приложение из области финансовых технологий:

* регистрация и вход клиента (пароли хранятся только в виде хеша PBKDF2-SHA256, блокировка после 3 неудачных попыток);
* открытие рублёвых счетов с 20-значным номером и корректным контрольным ключом (алгоритм Банка России, проверка по БИК);
* пополнение, снятие, переводы между счетами в одной транзакции БД;
* суточный лимит расходных операций, отправка операций от 600 000 ₽ на обязательный контроль (115-ФЗ) с решением офицера финмониторинга;
* идемпотентность операций (заголовок `Idempotency-Key`): повтор запроса не создаёт дубль платежа;
* журнал аудита, где номера счетов только в маске;
* кредитный калькулятор: аннуитетный и дифференцированный график, переплата;
* REST API и одностраничный веб-интерфейс.

## Стек

Python 3.11+, Flask, SQLite, pytest. Денежные суммы — `Decimal` и целые копейки, `float` не используется.

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python -m fintech.web              # http://127.0.0.1:5000
```

Docker:

```bash
docker build -t finwallet .
docker run -p 8000:8000 -e SECRET_KEY=change-me finwallet
```

## REST API

| Метод | Путь | Описание |
|---|---|---|
| POST | `/api/register` | регистрация `{login, full_name, password}` |
| POST | `/api/login` / `/api/logout` | вход / выход (cookie-сессия) |
| GET, POST | `/api/accounts` | список счетов / открыть счёт |
| GET | `/api/accounts/{n}/history` | история операций |
| POST | `/api/accounts/{n}/deposit` | пополнение `{amount}` |
| POST | `/api/accounts/{n}/withdraw` | снятие `{amount}` |
| POST | `/api/transfers` | перевод `{from, to, amount}` |
| GET | `/api/loan?amount=&rate=&months=&kind=` | график платежей |

Коды ответов: `200` — проведено, `202` — на проверке, `401` — нет входа, `422` — отклонено бизнес-правилом.

## Жизненный цикл разработки

1. **Анализ требований** — `docs/requirements.md`: функциональные и нефункциональные требования, регуляторные ограничения.
2. **Проектирование** — `docs/architecture.md`: слоистая архитектура, схема БД, план тестирования.
3. **Разработка** — пакет `fintech/` (money, security, loans, storage, services, web).
4. **Тестирование** — `tests/` (модульные и API-тесты), `bench.py` (нагрузка), CI в GitHub Actions.
5. **Внедрение** — `Dockerfile`, запуск через gunicorn, настройка через переменные окружения.
6. **Поддержка** — журнал аудита, версионирование (`fintech/__init__.py`), CHANGELOG, issues на GitHub.

## Структура

```
fintech/
  money.py      деньги: Decimal, копейки, валидация
  security.py   хеш паролей, маскирование, контрольный ключ счёта
  loans.py      кредитный калькулятор
  storage.py    SQLite, схема, транзакции
  services.py   бизнес-логика кошелька
  web.py        Flask: REST API + страница
  templates/    веб-интерфейс
tests/          pytest
docs/           требования и архитектура
```

> Проект учебный: БИК и номера счетов условные, реальные платёжные системы не подключены.
